# 消息排版与模板

入口：设置 → 界面 → 消息排版。改动立即应用于会话消息，实时预览使用同一套 Markdown 渲染。工具输出和文件预览沿用原有样式。

- 内置「原始」「舒适」「紧凑」模板，选择后仍可微调。
- 可调字体、字号、行高、段间距、列表间距、标题大小与留白、行内代码大小与底色、正文宽度、强调字重、表格样式与留白。
- 正文宽度为 0 时铺满，窄屏受可用宽度约束。宽表格在局部横向滚动，数值单元格保持完整。
- 字体使用当前设备已安装的字体，缺失时按字体栈回退。
- 可保存最多 12 个命名模板，删除模板不会改变当前消息排版。「恢复原始」恢复排版参数，保留已保存模板。

偏好保存在 `codex-deck:settings:v1` 的 `messageTypography` 与 `messageTemplates` 字段，随「设置 → 数据」的设置备份一起导入导出。旧 `readingSize` 在缺少新字段时迁移为对应字号，新字段优先。未保存排版偏好的设备使用原始模板。

参数、范围、内置模板和 CSS 变量映射统一定义于 `src/message-typography.ts`。导入数据经过枚举校验、数值边界限制和模板去重。页面渲染前由 `initializeDeckSettings()` 应用变量，设置变更及其他标签页的 storage 事件重新应用变量。
